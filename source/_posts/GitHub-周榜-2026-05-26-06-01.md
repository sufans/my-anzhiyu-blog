## 项目快速上手与避坑指南

### 1. openhuman

- ✅ **核心亮点**：(1) Rust+Tauri 构建，内存占用 200MB 以内，对比 Electron 动辄 1GB；(2) TokenJuice 压缩引擎在 LLM 调用前将上下文压缩至 20%，API 费用降低 80%；(3) 本地 SQLite 记忆树，20 分钟自动同步 118+ 服务，数据完全不上传云端。
- 🚀 **10秒试用**：`curl -fsSL https://raw.githubusercontent.com/tinyhumansai/openhuman/main/scripts/install.sh | bash`
- ⚠️ **避坑指南**：(1) 当前仍为 Early Beta，v0.53.x，频繁更新可能破坏配置，建议锁定版本；(2) 首次索引 118+ 服务需要 30-60 分钟，期间 CPU 占用较高，建议在空闲时段初始化。
- 🔄 **替代方案**：OpenClaw（375K Stars）—— 生态更成熟但为 TypeScript 全栈，资源占用更高；openhuman 胜在 Rust 性能和内存效率。

### 2. codegraph

- ✅ **核心亮点**：(1) tree-sitter 静态 AST 分析，无需向量嵌入 API，完全本地运行；(2) 支持 19+ 语言和 14 个框架的自动路由识别；(3) 实测在 50K 行代码库上减少 Agent 70% 工具调用次数和 35% token 消耗。
- 🚀 **10秒试用**：`npx @colbymchenry/codegraph`（自动索引当前目录）
- ⚠️ **避坑指南**：(1) 首次索引大型代码库（>5000 文件）需 5-10 分钟，可通过 `--max-files` 限制；(2) 动态语言（Python/JS）的调用关系解析不如静态语言（Go/Rust）准确，`get_callers` 可能遗漏反射调用。
- 🔄 **替代方案**：SocratiCode（向量搜索方案）—— 语义搜索更强但需 Qdrant 服务；codegraph 胜在零依赖和纯结构化查询。

### 3. agentmemory

- ✅ **核心亮点**：(1) LongMemEval-S 基准 R@5 达 95.2%，超过 mem0（68.5%）和 Letta/MemGPT（83.2%）；(2) 混合检索：BM25 + 向量 + 知识图谱三流融合，单次查询 14ms；(3) 支持 12+ Agent 共享同一记忆服务器，跨工具上下文不丢失。
- 🚀 **10秒试用**：`npx @agentmemory/agentmemory`（启动后访问 `http://localhost:3113` 查看记忆面板）
- ⚠️ **避坑指南**：(1) 记忆质量取决于写入内容，脏数据会让 Agent 重复犯错，建议定期清理过期记忆；(2) 不要存储 API 密钥或生产环境敏感信息到记忆中，所有数据存于本地 SQLite。
- 🔄 **替代方案**：mem0 —— 更轻量但检索精度低 27%；agentmemory 胜在基准数据和跨 Agent 共享能力。
