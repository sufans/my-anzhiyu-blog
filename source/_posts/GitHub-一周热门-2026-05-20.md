## CloakHQ/CloakBrowser

> **一句话核心功能**：一款能通过所有机器人检测测试的隐身 Chromium 浏览器，可作为 Playwright 的直接替代品。

| 项目信息 | |
|---------|--|
| GitHub | [CloakHQ/CloakBrowser](https://github.com/CloakHQ/CloakBrowser) |
| 本周 Star 增长 | ⭐ **8,997** |
| 总 Star 数 | 16,901 |
| 主要语言 | Python |

**详细功能说明：**

- **源码级指纹修补**：不是简单的 User-Agent 伪装，而是从 Chromium 源码层面修改浏览器指纹，包括 Canvas、WebGL、AudioContext 等深度指纹特征
- **30/30 检测全通过**：在所有主流机器人检测平台（如 Creep.js、Pixelscan、BrowserLeaks）上均通过了检测测试
- **Playwright 无缝替换**：API 设计与 Playwright 兼容，现有自动化脚本几乎无需修改即可迁移，大幅降低迁移成本
- **适用于数据采集和测试**：在合法的网页自动化测试、竞品分析、价格监控等场景中具有实用价值

> ⚠️ **注意**：请务必在合法合规的范围内使用此工具。绕过机器人检测可能违反部分网站的服务条款，请确保你的使用场景符合相关法律法规。

**快速上手：**

```python
from cloakbrowser import Browser

# 一行代码启动隐身浏览器
browser = Browser()
page = browser.new_page()
page.goto("https://example.com")
```

**适用人群**：Web 自动化测试工程师、数据分析师、以及需要进行合法网页自动化的开发者。

- **全能一体**：内置 `bun run`（脚本运行）、`bun install`（包管理）、`bun test`（测试）、`bun build`（打包）四大核心功能，无需额外安装 Webpack、Jest 等工具
- **原生兼容 Node.js 生态**：高度兼容现有的 npm 包和 Node.js API，迁移成本低

**快速上手：**

```bash
# 安装 Bun
curl -fsSL https://bun.sh/install | bash

# 创建项目并安装依赖（比 npm 快数倍）
bun init
bun install

# 运行脚本
bun run index.ts
```

**适用人群**：追求开发效率的 JavaScript/TypeScript 开发者，特别是对构建速度有高要求的前端和全栈工程师。
